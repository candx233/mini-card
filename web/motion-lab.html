时长与曲线：把 5 处散落的规格收敛成 3 档

改动量最小 / 视觉零风险

现在代码里是 .15s ease（6 处）、.18s cubic-bezier(.22,.61,.36,1)、.25s linear、.35s linear 各写各的。下面两条轨道跑同样距离，看的人能立刻分出「哪条是同一家人」。

两条轨道距离、速度一样，只有曲线不同
现在 · 4 条规格
0.18s cubic-bezier(.22,.61,.36,1) 开关 / 导航块
0.15s ease 颜色 / 描边 ×6 处
0.25s linear 音乐进度
0.35s linear 番茄进度
统一后 · 3 档 + 1 条特殊规则
200ms var(--ease-out) 交互反馈
120ms var(--ease-snap) 颜色 / 描边 / 阴影
200ms var(--ease-spring) 按压回弹
进度条：保持 linear 时长 = 推送间隔
反例：进度条不要跟着统一成缓动
linear 正确：匀速 = 真的在走 2s 走完
ease-out 错误：前快后慢，看着像卡住 同样 2s
  • 新增 6 个变量：--dur-fast/normal/slow + --ease-out/snap/spring，把现有 5 处硬编码换成变量，视觉变化只有 ±20ms 和收尾曲线，不改布局、不改尺寸。
  • 关键取舍：进度条继续用 linear。它表示的是真实时间在流逝，一旦套上缓动，用户会觉得「进度条在骗我」。这条写进令牌注释，避免以后被一起「统一」掉。
/ 落点：card.html 的 .card / .td-ck / .pomo-track .bar>i / .mc-prog .bar>i，index.html 的 .switch / .nav-pill / .opt

单独一轮 / 只给低频数字

现在每次 render 都整段重写 innerHTML，数字是瞬变的。改法：每位数字一列 0–9（末尾再补一个 0 用于 9→0 进位），translateY 滚到位。点下面的按钮给两边同时跳时间。

  • 每列 11 格：0…9 + 再一个 0。9→0 时先滚到第 10 格（视觉上就是 0），transition:none 归位到第 0 格 —— 两格字一样，看不出接缝。
  • 宽度用 1ch（等宽数字的「0」宽度），和时间串逐字宽度一致，不会因为换成列而整体变宽变窄。
  • 只建议给低频数字用：时钟、番茄的分钟位、天气温度。网速（1s 一刷）不做 —— 令牌里 settle 300ms，每秒滚一次等于永不停歇。
